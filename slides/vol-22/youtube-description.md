## 概要欄

初心者向けPower Automateハンズオン勉強会「PA45」第22回の録画です。
テーマ：OfficeスクリプトとCopilotで、Excelの手作業を自動化

「Excelの同じ集計、毎回手でやっている」を今回で卒業します。プログラミングは書きません。やることは、Copilotにスクリプトを作ってもらう → Excelに貼って動かす → Power Automateのフローから呼び出す、の3ステップ。題材は「経費集計の自動化」。非IT・初参加の方も歓迎です。

📌 今回のポイント
・Officeスクリプトって何？：Excel Onlineの「自動化」タブから使う、クラウド版のマクロ
・コードは書かない：やりたいことを日本語でCopilotに頼むと、スクリプトを作ってくれる
・貼って動かす：もらったスクリプトを「自動化」タブに貼って保存 →「実行」で一発
・フローから呼べる：Power Automateの「スクリプトの実行」で呼び出し、戻り値で分岐できる
・通知まで自動：集計 → 判定 → Teams通知まで、フローがまとめて面倒を見る
・⚠️ VBAマクロとの違い：デスクトップのExcelマクロ（VBA）とは別物。クラウドで動く
・💰 お金の話：使えるプランを先に確認（対応ライセンスが要る点に注意）
