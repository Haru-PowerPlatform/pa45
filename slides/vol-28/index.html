PA45｜第28回 ／ 下ごしらえ

SharePointに「今日のやること」を作る

Setup
  1. SharePointのサイトで、リスト 今日のやること を新規作成する
  2. 列を追加する。ここで名前は半角の Done にする（種類＝はい/いいえ）
  3. 作ったあとに、表示名だけ「完了」に変更する
  4. Title に3件入れる（例：見積書を送る／議事録を共有する／請求書を確認する）
なぜ半角で作ってから名前を変えるのか。 SharePointは作ったときの名前が「内部名」として固定され、あとから表示名を変えても内部名は変わりません。 日本語で作ると内部名が _x5b8c__x4e86_ のような文字列になり、フローから指定できなくなります。

PA45｜第28回 ／ ②カードを送る

このアクションは、止まって待ちます

Step 2
⏸️アダプティブ カードを Teams ユーザーに投稿して応答を待機する
カードを送ったあと、フローはそこで止まります。誰かが送信ボタンを押すまで、次のアクションには進みません。押された瞬間に、その答えを持って再開します。

ふつうの投稿との違い

「メッセージを投稿する」は送って終わり。こちらは返事が返ってくるまで待ちます。だから、答えを次の処理に使えます。

設定するところ

  • 投稿者＝フローボット
  • 投稿先＝ユーザーとのチャット
  • 受信者＝自分（テストのため）
  • メッセージ＝カードのJSON
前提：Teamsに「Workflows（ワークフロー）」アプリが入っていること。自分あてに送れば、その場でテストできます。

PA45｜第28回 ／ ★今日の山場

返ってくるのは、文字列の「true」

Key
これでとれる
outputs('カードを投稿して応答を待機') ?['body/data/t1']
→ 返ってくるのは "true"。チェックが1つぶんの答えです。
これはとれない
outputs('カードを投稿して応答を待機') ?['body/data']
→ 返ってくるのはかたまり（Object）。文字列ではないので、文字を切る関数は使えません。
ここを間違えると、こう言われます。 「かたまり」に対して文字列の関数（split など）を使うと、下のようなエラーになります。 true は「はい/いいえ」ではなく、true という4文字だと覚えてください。
The template language function 'split' expects its first parameter to be of type string. The provided value is of type 'Object'.

英語のまま貼るのが、いちばん早い

やること
Power Automateで このエラーが出ました。 （エラー文を全文そのまま貼る） 意味と、直す場所を教えてください。
なぜ訳さないか
  • エラー文にはアクション名・行・型が入っている

  • 全文貼ればどこを直すかまで返ってくる

PA45｜第28回 ／ 発展・注意

使える場面と、知っておくこと

More
📥

こんな場面に

  • 日々の点検表・チェックリスト
  • 引き継ぎ事項の消し込み
  • 持ち物・提出物の確認
🔧

発展

  • 件数に合わせてチェックを増やす
  • チェックしなかった分を翌日に繰り越す
  • 完了した件数を集計する
⚠️

注意

  • 今日は3件で固定。件数が変わる形は発展編
  • 3件未満のときはカードの行が空になる
  • Teamsに「ワークフロー」アプリが要る
なぜ3件で固定するのか。 リストの件数に合わせてカードの行を増やす作りにすると、JSONを組み立てる処理が必要になり、45分では終わりません。 まず固定で動かす。動いてから増やすのが、いちばん早い道です。
