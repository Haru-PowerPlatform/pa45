PA45｜第27回 ／ 始める前に👀 見るだけ

その前に — Think Deeper に切り替える

前提
Copilot にはじっくり考えるモードがあります。通常のモードは速く返る代わりに、長いものを渡すと読み飛ばします。Power Automate の相談は、こちらに切り替えてからのほうが当たります。

切り替えたほうがいい相談

・⑤ JSONを丸ごと読ませる（いちばん効きます）
・③ エラーの原因を追う
・フロー全体を作り直したい

通常のままでいい相談

・アクションの日本語名を聞く
・式を1行もらう
（待ち時間のほうが長くなります）

切り替え方。Copilot の入力欄まわりにあるモードの選択から Think Deeper を選びます。返事までに時間がかかります——待ちます。（画面の場所や呼び方は変わることがあります）

PA45｜第27回 ／ 渡し方①👀 見るだけ

まず、フロー全体のスクショを渡す

① 全体
1
Copilot はあなたの画面を見ていません。文章で説明しようとすると長くなり、しかも伝わりません。デザイナーを開いて、全体が入るように撮って貼るのが最短です。
Power Automate のフローについて相談です。 いまのフロー全体のスクリーンショットを貼ります。 （フロー全体のスクショを貼る） ・このフローが何をしているのか ・「○○したい」のですが、どのアクションを直せばよいか 日本語で教えてください。
撮り方のコツ。アクションはすべて閉じた状態で撮ります。開いたまま撮ると1つしか写らず、全体の流れが伝わりません。長いフローは2枚に分けて貼れば読めます。

PA45｜第27回 ／ 渡し方②👀 見るだけ

次に、実行履歴の「出力」を渡す

② 実行履歴
2
全体のスクショは形しか伝わりません。中を流れたデータの実物を渡すと、答えが具体的になります。

どこを見るか

フローの画面 → 28日間の実行履歴 → 行をクリック → アクションを開いて「出力」

なぜ効くのか

項目名は環境ごとに違います。見せない限り Copilot は推測で答えるしかありません

★ ここは覚えて帰ってください。出力欄の表示は見やすく整形されたものです。「未加工の出力を表示する」を開くと本物のJSONが出ます。Copilot に渡すのはこちら。整形された画面から書き写すと、項目名が実物と変わることがあります。

PA45｜第27回 ／ 渡し方③👀 見るだけ

エラーは、スクショごと渡す

③ エラー
3
エラーは訳さない・要約しない・そのまま渡す。自分で言い換えると、原因の手がかりが落ちます。
Power Automate のフローが失敗しました。 失敗したアクションの画面を貼ります。 （赤くなったアクションのスクショを貼る） ・何が起きているのか ・どのアクションの、どの設定を直せばよいのか 初心者にも分かる言葉で、日本語で教えてください。
スクショが効く理由。エラー文だけコピーすると、どのアクションで出たかが抜けます。スクショならアクション名・設定・エラー文が1枚に写るので、Copilot が場所まで特定できます。

PA45｜第27回 ／ 渡し方④👀 見るだけ

「日本語で」を必ず足す

④ 日本語
4
Copilot は Power Automate の話になると、アクション名も式も英語で返してきます。ところが日本語環境の画面には、その名前はどこにも出てきません。

こう返ってくる

Add a Create HTML table action…
→ 画面で探しても見つからない

こう足す

「回答は日本語で。
アクション名は 英語名（日本語名）の形で両方書いてください」

★ 両方ほしい理由。日本語名は画面で探すため、英語名は検索やドキュメントを読むために要ります。一度で直らないのが普通なので、英語のまま返ってきたらもう一度頼めば直ります。

PA45｜第27回 ／ 渡し方⑤👀 見るだけ

いちばん正確なのは、ZIPの中のJSON

⑤ JSON
5
スクショは見えている部分だけです。折りたたまれた設定・条件の中身・式は写りません。フローの中身そのもの（JSON）を渡すと、抜けがなくなります。

スクショで足りるとき

・全体の流れを知りたい
・エラーを1つ直したい

JSONが要るとき

・引き継いだフローを全部理解したい
・式や条件の中身まで見てほしい

とはいえ、編集画面からは取り出せません。フローを開いた画面の中に「エクスポート」はありません。ソリューション経由で書き出します。次のページで手順を通しでやります。

PA45｜第27回 ／ 渡し方⑤ の手順👀 見るだけ

ソリューションからZIPを出して、中のJSONを取り出す

手順

① 書き出す

1. 左メニュー ソリューション → ＋ 新しいソリューション
2. 開いて 既存項目の追加 → クラウド フロー でそのフローを選ぶ
3. 一覧でその行を選んで「エクスポート」
4. アンマネージドを選んでダウンロード

② 中身を出す

5. ZIPを右クリック → すべて展開
6. Workflows フォルダを開く
7. 中の .json をメモ帳で開く
8. 全選択してコピーし、Copilot に貼る

★ つまずくのは 3 です。「エクスポート」はフローを開いた画面の中にはありません。ソリューションの一覧側で、その行にチェックを入れると上に出てきます。
アンマネージドを選びます。マネージドは配布用で、中身を編集できない形になります。

PA45｜第27回 ／ 渡し方⑤👀 見るだけ

JSONを渡して、説明させる

⑤ 実演
取り出したJSONを、そのまま貼ります。長くても大丈夫です。
これは Power Automate のフローの中身（JSON）です。 （Workflows フォルダの .json を全部貼る） ・このフローが何をしているのか、上から順に ・つまずきそうな所はどこか Power Automate を触ったことがない人にも分かる言葉で、日本語で説明してください。
引き継ぎのときに、いちばん効きます。作った人がいない・コメントも無い・でも直さないといけない。そういうフローを読める形に翻訳させる使い方です。

PA45｜第27回 ／ 注意👀 見るだけ

貼る前に、必ずやること

注意

🔒 機密は置き換える

会社名・氏名・メールアドレス・取引先名・金額。スクショにも写ります

🔍 そのまま信じない

関数名は公式の関数リファレンスで確かめる。引用元が中身と無関係なことがあります

⬜ 空欄を疑う

必須の欄が空のまま返ることがあります。空欄は人に渡された場所

★ JSONを貼るときは特に注意。ZIPの中には環境のIDや接続の情報も入っています。社外のAIに貼る前に、会社のルールを確認してください。
