そのまま貼れる Copilot プロンプト集

Copilot への相談は、質問の文章より「何を渡すか」で答えが変わります。
黄色の部分を自分の内容に置き換えて、Copilot チャットに貼ってください。

★ その前に：Think Deeper に切り替える
Copilot にはじっくり考えるモードがあります。通常のモードは速く返る代わりに、長いものを渡すと読み飛ばします。入力欄まわりのモード選択から Think Deeper を選んでから貼ってください。
特に 5（JSONを丸ごと渡す） と 3（エラーの原因を追う） で差が出ます。アクション名を聞くだけ・式を1行もらうだけなら、通常のままで十分です（待ち時間のほうが長くなります）。
※ 画面の場所や呼び方は変わることがあります。

1フロー全体のスクリーンショットを渡す

Copilot はあなたの画面を見ていません。文章で説明するより、デザイナーを開いて全体を撮って貼るほうが速く、正確です。アクションはすべて閉じた状態で撮ってください。開いたままだと1つしか写りません。

Power Automate のフローについて相談です。
いまのフロー全体のスクリーンショットを貼ります。

（フロー全体のスクショを貼る）

・このフローが何をしているのか
・「○○したい」のですが、どのアクションを直せばよいか

日本語で教えてください。

2実行履歴の「出力」を渡す

全体のスクショでは形しか伝わりません。中を流れたデータの実物を渡すと、答えが具体的になります。項目名は環境ごとに違うので、見せない限り推測で答えるしかありません。

どこを見るか
フローの画面 → 28日間の実行履歴 → 行をクリック → アクションを開いて「出力」
★ 「未加工の出力を表示する」から取ること。画面の表示は見やすく整形されたものです。整形された表示から書き写すと、項目名が実物と変わってしまうことがあります。 
Power Automate のフローの、実行履歴の出力を貼ります。

（「未加工の出力を表示する」の中身をそのまま貼る）

・この中の 「○○」 を次のアクションで使いたいです
・動的コンテンツの選び方か、式のどちらかで教えてください

日本語で教えてください。

3エラーは、スクリーンショットごと渡す

訳さない・要約しない・そのまま渡す。エラー文だけコピーするとどのアクションで出たかが抜けます。スクショなら、アクション名・設定・エラー文が1枚に写ります。

Power Automate のフローが失敗しました。
失敗したアクションの画面を貼ります。

（赤くなったアクションのスクショを貼る）

・何が起きているのか
・どのアクションの、どの設定を直せばよいのか

初心者にも分かる言葉で、日本語で教えてください。

4「日本語で」を必ず足す

Copilot は Power Automate の話になると、アクション名も式も英語で返してきます。ところが日本語画面には Create HTML table という名前はどこにも出てきません。日本語名は画面で探すため、英語名は検索やドキュメントを読むために要るので、両方もらいます。

Power Automate で （やりたいこと） をしたいです。

私の画面は日本語表示です。
回答は日本語で書いてください。
アクション名は「英語名（日本語名）」の形で、両方書いてください。
設定する項目の名前も、日本語画面での表示名で書いてください。

初心者なので、順番に、何をどこに入れるかまで教えてください。
英語のまま返ってきたら、もう一度頼めば直ります。一発で決まらないのが普通です。

5ZIP の中の JSON を渡す（いちばん正確）

スクショに写るのは見えている部分だけです。折りたたまれた設定・条件の中身・式は写りません。引き継いだフローを全部理解したいときや、式まで見てほしいときは、フローの中身そのもの（JSON）を渡します。

取り出し方（編集画面からは取り出せません）
  1. 左メニュー ソリューション → ＋ 新しいソリューション を作る
  2. 開いて 既存項目の追加 → クラウド フロー で、そのフローを選ぶ
  3. 一覧でその行を選んで「エクスポート」 — ★ここでつまずきます。エクスポートはフローを開いた画面の中にはありません。ソリューションの一覧側で行にチェックを入れると上に出てきます
  4. アンマネージドを選んでダウンロード（マネージドは配布用で、中身を編集できません）
  5. ZIPを右クリック → すべて展開
  6. Workflows フォルダを開き、中の .json をメモ帳で開く
  7. 全選択してコピーし、Copilot に貼る
これは Power Automate のフローの中身（JSON）です。

（Workflows フォルダの .json を全部貼る）

・このフローが何をしているのか、上から順に
・つまずきそうな所はどこか

Power Automate を触ったことがない人にも分かる言葉で、日本語で説明してください。
⛔ 貼る前に、必ず
  • 会社名・氏名・メールアドレス・取引先名・金額は、サンプルの値に置き換えてから貼る
  • 返ってきた答えはそのまま信じない。引用元として示されたページが、中身と関係ないことがあります
  • 必須の欄が空のまま返ってくることがあります。空欄は、AIが人に渡した場所だと思ってください
  • ZIP の中には環境のIDや接続の情報も入っています。社外のAIに貼る前に、会社のルールを確認してください
うまくいかないときは、会話を続ける
一発で正解が返ってこないのが普通です。「その表に余計な列が出ます」「もっと短く」のように、 返ってきた答えに対してもう一度頼むと、ぐっと近づきます。
