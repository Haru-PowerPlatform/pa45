PA45｜第29回 ／ 5分で復習

スラッシュは「の中の」と読む

Review
body('メールの取得 (V3)…')?['value']?[0]?['subject']

左から順に読むだけ

  • body(アクション名) ＝ そのアクションの結果の箱
  • ?['value'] ＝ その中の「value」という箱
  • ?[0] ＝ その中の1件目
  • ?['subject'] ＝ その中の「件名」

クエスチョンマークの意味

?（はてな）は「無かったら、そこで止めて空にする」という印です。付けないと、値が無いときにフローが赤く止まります。

迷ったら全部の [ の前に ? を付けておく、で構いません。付けすぎても動きます。

Key
{ "body": { "value": [ ← ここが [ ]。5件ならんでいる { "subject": "【見積】9月分のご請求について", ← [0] 1件目 "from": "jido.hajime@contoso.com" }, { "subject": "アンケートに新しい回答が届きました" }, ← [1] 2件目 { "subject": "来週の打ち合わせ資料です" } ← [2] 3件目 ] } }

Expressions

PA45｜第29回 ／ 実機で確かめる

差出人は、これ以上ほどけない

Check

このコネクタの from

"from": "jido.hajime@contoso.com"

アドレスの文字がそのまま入っています。だから ?['from'] で終わり。

他のサービスだと、こうなる
