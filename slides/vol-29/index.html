PA45｜第29回 ／ 5分で復習

スラッシュは「の中の」と読む

Review
body('メールの取得 (V3)…')?['value']?[0]?['subject']

左から順に読むだけ

  • body(アクション名) ＝ そのアクションの結果の箱
  • ?['value'] ＝ その中の「value」という箱
  • ?[0] ＝ その中の1件目
  • ?['subject'] ＝ その中の「件名」

クエスチョンマークの意味

?（はてな）は「無かったら、そこで止めて空にする」という印です。付けないと、値が無いときにフローが赤く止まります。

迷ったら全部の [ の前に ? を付けておく、で構いません。付けすぎても動きます。

Key

1件目・件数・最後は、この3つ

Expressions
式読み方結果（実機）
first(body('メールの取得 (V3)（受信トレイから5件）')?['value'])?['subject']棚のいちばん前の、件名【見積】9月分の…
body('メールの取得 (V3)（受信トレイから5件）')?['value']?[1]?['subject']棚の2件目の、件名アンケートに新しい…

PA45｜第29回 ／ 実機で確かめる

差出人は、これ以上ほどけない

Check

このコネクタの from

"from": "yamada.taro@contoso.com"

アドレスの文字がそのまま入っています。だから ?['from'] で終わり。

他のサービスだと、こうなる

"from": { "emailAddress": { "address": "yamada.taro@…" } }

同じ「差出人」でも3階層。?['from']?['emailAddress']?['address'] と続きます。

だから、毎回その場で出力を見ます。 「差出人はこう書くもの」と暗記していると外します。目の前の出力がすべてです。 ちなみに今回、「添付あり？」が いいえ なのに attachments に3件入っている通がありました。本文に埋め込まれた画像です。

PA45｜第29回 ／ まとめ

今日そろえたもの

Wrap

できるようになったこと

  • 出力を開いて、値の住所を読む
  • 1件目・2件目・最後を名指しで取り出す
  • 件数を数える
  • 全件から1列だけ抜いて、1行にまとめる

Copilotへの聞き方

  • 出力を先に見せる
  • 要らない部分を消してから貼る
  • アクション名を書き添える
