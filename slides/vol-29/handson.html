PA45 第29回｜ハンズオン手順

動的コンテンツに出てこない値も、Copilotと一緒に式で取り出せるようになる毎朝、練習用に送った3通をとってきて、1件目の件名・件数・最後の1件・全件の件名を取り出し、Teamsに1通でまとめて届けます。動的コンテンツの一覧に出てこない値を、自分の手で取り出せるようになります。

今日つくるもの： 毎朝8時に動いて、件名に PA45 が入ったメールを新しい順にとってきて、件数・1件目・2件目・最後・全件の件名を並べた1通のメッセージを自分あてのTeamsに届けるフロー。
⏰ 繰り返し（毎朝8時）→ 📥 PA45のメールを取得→ 🔍 出力を読んで式にする→ 📨 Teamsに1通
🔰 初参加の方へ： ここから始めて大丈夫です。用意するものはありません（リストもフォームも作りません）。最初に自分あてに練習用のメールを3通送るところから始めます。第14回「JSONの読み方」に出ていなくても、STEP 3 で復習します。
目次 0. 自分あてに3通送る 1. 繰り返しで始める 2. メールを5件とってくる 3. 1回動かす 4. Teamsに件名を送ってみる 5. 件数を探してみる 6. 出力を読む 7. 枠を外して件数 8. 1行ずつ足す 9. 全件を1行に 10. 仕上げてテスト ＋ Copilotに聞く3か所
STEP 0第1章 まず動かす

自分あてに、練習用のメールを3通送る（3分）

いきなり受信トレイを読むと、人によって件数も中身もばらばらになります。画面共有をしていると本物のメールも映ります。そこで、自分で送った3通だけを読む形にします。

  1. Outlook で 自分あてに3通送ります。件名の先頭に PA45 を付けます。
  2. 件名の例：PA45 見積の件 ／ PA45 議事録の共有 ／ PA45 来週の打ち合わせ
  3. 本文は空でかまいません。3通で30秒ほどです。
  4. 受信トレイに3通とも届いたのを、目で確かめてから次へ進みます。
    • 届くまで数十秒かかることがあります。0通のままフローを動かすと、件数が 0 になって何も出ません。
⚠️ もし届いていなかったら： あわてず、もう1通送って少し待ちます。件数が 0 のときにどう見えるかも、今日の確認ポイントのひとつです（length() が 0、first() は空）。フローは壊れていません。
💡 こうしておくと、あとが楽です。 全員の結果がそろうので、式の答え合わせができます。件数も件名も、手元と画面で同じものが出ます。
■ 自分あてにメールを送れない環境のときは：
  • 案A（おすすめ）：件名に PA45 を付けて自分あてに3通。全員同じ結果になります。
  • 案B：送れない場合は、すでに受信トレイにある言葉で絞ります（例：件名フィルターに お知らせ）。件数は人それぞれになりますが、式はまったく同じです。
  • 案C：どちらも難しければ、手を動かさず画面を見るだけで大丈夫です。式の読み方は、講師の画面の出力で追えます。
⚠️ 会社のメールを画面共有するとき： 受信トレイをそのまま開くと、取引先名や件名が映ります。今日は件名フィルターで自分の3通だけに絞るので、実行結果にも他のメールは出てきません。
STEP 1

繰り返し（毎朝8時）で始める

Power Automate で 「作成」→「スケジュール済みクラウド フロー」を選びます。時刻で自動的に始まるフローです。作っている途中は テスト → 手動 でいつでも動かせます。

  1. フロー名は 毎朝のメールをまとめて知らせる など、分かる名前にします。
  2. 開始日時は今日、繰り返し間隔は 1 日。作成を押します。
  3. トリガー「繰り返し」を開いて、タイム ゾーンを (UTC+09:00) 大阪、札幌、東京、設定時刻 (時間) を 8 にします。
  4. アクション名を 繰り返し（毎朝8時に動かす） に変えます。
    • 元の名前「繰り返し」は消さずに、かっこで説明を足すだけにします。あとで見たときに、何のアクションか分かるようにするためです。
💡 タイム ゾーンを忘れると9時間ずれます。 既定は協定世界時（UTC）なので、日本時間の朝8時にしたいときは必ず東京に変えます。
STEP 2

PA45のメールだけ、新しい順にとってくる

Office 365 Outlook の 「メールを取得する (V3)」を追加します。「メールが届いたとき」ではありません。まとめて何件も返ってくるアクションです。

  1. ＋新しいステップ→ Office 365 Outlook → 「メールを取得する (V3)」を追加します。
  2. 欄を埋めます。詳細オプションを開くと下の欄が出てきます。
    フォルダーInbox件名フィルターPA45未読のみを取得しますか?いいえ添付ファイルを含めるいいえ上位5
  3. アクション名を メールを取得する (V3)（PA45のメールを5件） に変えます。
    • 「メールを取得する (V3)」の部分は1文字も変えません。（V3）も半角のまま残します。あとで式の中にこの名前をそのまま書きます。
⚠️ 「上位」を大きくしすぎない。 100件にすると、返ってくる出力も100件分になります（本文のHTMLも全部入るため、とても大きくなります）。まずは5件で作り、動いてから増やします。
STEP 3

まず1回動かして、緑になるのを見る

  1. 右上の 「保存」→ 「テスト」→ 「手動」→ 「テスト」で動かします。
  2. 2つのアクションに緑の✓が付けば成功です。取ってきた中身は STEP 6 で開きます。
STEP 4第2章 つまずく

取ってきた件名を、Teamsに送ってみる

オートさんと同じことをやってみます。うまくいかないのが正解のステップです。

  1. 「メールを取得する (V3)」の下の ＋ → Microsoft Teams → 「チャットまたはチャネルでメッセージを投稿する」を追加します。
  2. 欄を埋めます。
    投稿者フロー ボット投稿先チャット（フロー ボットと）Recipient自分のアドレス
  3. メッセージ欄に 件名： と打ち、動的コンテンツの「件名」を選びます。
  4. Teams のアクションが、繰り返しの枠に勝手に入ります。
  5. 「保存」→「テスト」→「手動」で動かします。自分あてに 3通バラバラに届きます。
■ なぜ3通に分かれるのかは STEP 6 で出力を見ると分かります。枠は STEP 7 で外します。
STEP 5第2章 つまずく

「件数」を、動的コンテンツの一覧で探してみる

  1. Teams のメッセージ欄で、動的コンテンツの一覧を開きます。
  2. 「件数」や「全件の件名」を探します。どこにもありません。
💡 ここからが今日の本題です。 一覧に無い値は、出力を読んで式で取り出します。
STEP 6第3章 出力を読む

出力を開いて、件名がどこにあるか読む

ここが今日のいちばん大事な手順です。出力を見てから式を書きます。逆にすると、名前を当てずっぽうで書くことになり、ほぼ外します。

  1. STEP 4 のテスト結果の画面で、「メールを取得する (V3)（PA45のメールを5件）」をクリックして開きます。
  2. 出力の欄を見ます。value の [ ] の中に、件名が3件並んでいます。だから「件名」を選ぶと、1件ずつの繰り返しになりました。
■ 出力の形（実際に動かして確かめたもの）：
  • いちばん外は body。その中に value という名前の配列（[ ]）があり、5件が並んでいます。
  • 1件の中に subject（件名）、from（差出人）、receivedDateTime（受信日時）などが入っています。
  • 差出人はアドレスの文字がそのまま入っています（このコネクタは中身を平らにして返します）。
出力の形（要らないところを消したもの） 
{
  "value": [
    { "subject": "PA45 見積の件",
      "from": "jido.hajime@contoso.com",
      "receivedDateTime": "2026-09-25T09:02:53+00:00" },
    { "subject": "PA45 議事録の共有" },
    { "subject": "PA45 来週の打ち合わせ" }
  ]
}
⚠️ 出力は、そのままコピーしないでください。
  • 実際の出力は5件で約29万文字あります。大半は配送の記録（internetMessageHeaders）と本文のHTMLです。
  • 中には差出人・宛先・本文が入っています。Copilotに貼るときは、1件だけ・要る名前だけに削ってから貼ります（上のコピー用がその形です）。
💡 かっこの読み方（第14回の復習）： { } は名前で取る（お弁当箱）、[ ] は番号で取る（棚）。棚の1件目は [0] で、人の数え方と1つずれます。
STEP 7第4章 取り出す

3通に分かれる枠を外して、件数を出す

  1. 繰り返しの枠の 「…」→「削除」。中の Teams も一緒に消えます。
  2. 「メールを取得する (V3)」の下に、Teams 「チャットまたはチャネルでメッセージを投稿する」をもう一度足します（欄は STEP 4 と同じ）。
  3. アクション名を チャットまたはチャネルでメッセージを投稿する（5件をまとめて知らせる） に変えます。
  4. メッセージ欄に PA45のメール： と打ち、続けて式（fx）で下の「件数」を入れ、件 と打ちます。
  5. テスト。1通だけ、「PA45のメール：3 件」と届けば成功です。
件数 
length(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])
STEP 8第4章 取り出す

1件目・2件目・最後・差出人を、1行ずつ足す

Teams のメッセージ欄に、1行足すたびにテストします。行の頭に「1件目の件名：」などの言葉を打ち、続けて式（fx）で入れます。動的コンテンツの一覧には、どれも出てきません。

① 1件目の件名 
first(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])?['subject']
② 2件目の件名（番号で取る） 
body('メールを取得する (V3)（PA45のメールを5件）')?['value']?[1]?['subject']
③ 最後の1件の件名 
last(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])?['subject']
④ 1件目の差出人 
first(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])?['from']
■ 式の読み方（左から順に）： body(アクション名)＝そのアクションの結果の箱 → ?['value']＝その中の value という箱 → ?[1]＝その中の2件目 → ?['subject']＝その中の件名。? は「無かったら空で止める」印です。
⚠️ 式の中のアクション名は、自分の画面と一字一句同じに。 空白もかっこもそのままです。アクション名を変えたら、式の中も直します。分からないときは、アクションの「…」→「コードの表示」で中の名前を確かめます。
💡 赤くなったら、直前に足した1行が原因です。 一度に全部貼らないのはそのためです。
💡 first() と ?[0] は同じ意味です。 0件のときに赤く止まりにくいのは first() のほうです。
STEP 9第4章 取り出す

全件の件名を、1行にまとめる

5件ぜんぶの件名を並べたいときは、繰り返し（Apply to each）を使いません。「選択」で1列だけ抜いて、join() でつなぎます。

  1. 「メールを取得する」と Teams のあいだの ＋ → データ操作 → 「選択」を追加します（Teams より上に置きます）。
  2. 2つの欄を埋めます。どちらも式（fx）で入れます。
    開始body('…')?['value']マップitem()?['subject']
  3. アクション名を 選択（件名だけを取り出す） に変えます。
  4. Teams のメッセージ欄に 全件の件名： と打ち、式（fx）で下の join を入れてテスト。
「開始」に入れる式 
body('メールを取得する (V3)（PA45のメールを5件）')?['value']
「マップ」に入れる式 
item()?['subject']
Teams の本文に足す式 
join(body('選択（件名だけを取り出す）'), ' / ')
■ item() とは： 「いま見ている1件」を指す言葉です。選択は、棚に並んだ1件ずつに対して「この名前のところだけ取り出して」と伝えるアクションです。結果は件名だけが並んだ配列になります。
STEP 10第5章 届ける

本文を整えて、もう一度テスト（完成）

完成した本文の見本（足りない行があれば足す・アクション名はご自分のものに） 
PA45のメール：@{length(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])} 件
1件目の件名：@{first(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])?['subject']}
1件目の差出人：@{first(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])?['from']}
2件目の件名：@{body('メールを取得する (V3)（PA45のメールを5件）')?['value']?[1]?['subject']}
最後の1件：@{last(body('メールを取得する (V3)（PA45のメールを5件）')?['value'])?['subject']}
全件の件名：@{join(body('選択（件名だけを取り出す）'), ' / ')}
  1. 「保存」→ 「テスト」→「手動」で実行します。
  2. Teams のフロー ボットから、1通だけ届きます。件数と件名が入っていれば完成です。
  3. 各アクションを開いて、入力と出力も見てみてください。式が何を返したかが残っています。
  4. 試し終わったら、フローをオフに戻します（毎朝8時に動き続けるため）。
うまくいかないとき：
  • 式が赤い → アクション名が画面と違います。「コードの表示」で中の名前を確かめます。
  • 値が空になる → [ ] の番号がずれています。1件目は [0]、2件目は [1] です。
  • 件数が 0 → 「上位」が空になっていないか、フォルダーが Inbox になっているかを確認します。
  • メッセージが届かない → Recipient が自分のアドレスになっているか確認します。
  • 英語のエラーが出た → 読まずに、そのままコピーしてCopilotに貼ります（下の③）。
＋

Copilotに聞く3か所（そのまま貼れます）

手を動かすのは自分、分からないところだけ聞く、という使い方です。Power Automate内蔵のCopilotではなく、M365 Copilot チャットに貼ってください。

① 出力を先に見せて、式を作ってもらう（いちばん効きます）

出力を貼らずに聞くと、名前を推測した式が返ってきて、そのままでは動きません。貼るのは1件だけ・要る名前だけに削ったものです。

Power Automate の式を1行だけ教えてください。説明は不要です。
アクション名は「メールを取得する (V3)（PA45のメールを5件）」です。
このアクションの出力は次の形です（関係ない部分は消しています）。

{
  "value": [
    { "subject": "PA45 見積の件",
      "from": "jido.hajime@contoso.com" }
  ]
}

1件目の件名を取り出す式を書いてください。

② 返ってきた式の意味を、日本語で説明してもらう

Power Automate のこの式を、プログラミングを知らない人向けに説明してください。

first(body('メールを取得する (V3)')?['value'])?['subject']

とくに、? と [ ] と ' ' がそれぞれ何をしているのかを教えてください。

③ エラー文は、訳さずそのまま貼る

Power Automateでこのエラーが出ました。

（エラー文を全文そのまま貼る）

意味と、どこを直せばよいかを教えてください。
⚠️ 貼る前に一度だけ確認： 社名・氏名・取引先・メールアドレスが混ざっていないか見てください。混ざっていたら、架空の名前に置き換えてから貼ります。
💡 一発で終わらなくて普通です。 返ってきた式を試して、違ったらその結果をまた貼る。会話を続けるのが正しい使い方です。
