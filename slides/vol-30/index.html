準備

作る前に、Copilot にカードと期日の式を1回で頼む

オートさんカードの JSON と期日の式は、Copilot に1回で作ってもらおう
M365 Copilot チャットに、この指示を1回送る
Power Automate で使うものを2つ作ってください。説明は不要で、2つだけ返してください。

① Teams のアダプティブ カードの JSON（バージョン 1.4）
・見出し：To Do に追加します
・入力1：期限（日付を選ぶ）。id は dueDate。ラベルは「期限（空なら3日後）」
・入力2：重要度（高・標準・低から1つ）。id は importance。値は high / normal / low。初期値は normal
・入力3：メモ（複数行・空でもよい）。id は memo
・ボタンは「追加する」1つ

② To Do の「期日」に入れる式を1行で
・triggerBody()?['cardOutputs']?['dueDate'] が空なら今日から3日後、入っていればその日
・形は yyyy-MM-ddT00:00:00

  "type": "AdaptiveCard",
  "$schema": "http://adaptivecards.io/schemas/adaptive-card.json",
  "version": "1.4",
  "body": [
    { "type": "TextBlock", "text": "To Do に追加します", "weight": "Bolder", "size": "Medium" },
    { "type": "Input.Date", "id": "dueDate", "label": "期限（空なら3日後）", "isRequired": false },
    { "type": "Input.ChoiceSet", "id": "importance", "label": "重要度", "style": "expanded", "value": "normal",
      "choices": [
        { "title": "高", "value": "high" },

    { "type": "Input.Text", "id": "memo", "label": "メモ", "isMultiline": true, "isRequired": false }
