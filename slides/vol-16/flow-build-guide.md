## 題材

**Formsの回答が届いたら → 受付日を日本語の日付に整えて → 自分にメール通知**

---

## 作り方

### 1. 新規作成
`作成` → `自動化したクラウド フロー`
- 名前：**PA45-No16-CopilotAssist**
- トリガー：**Microsoft Forms「新しい応答が送信されるとき」** → 作成

### 2. トリガー設定
- **フォーム**：`PA45アンケートサンプル`（どのフォームでもOK）

### 3. ＋新しいステップ → Microsoft Forms「応答の詳細を取得する」
- **フォーム**：同じものを選択
- **応答ID**：クリック → 動的コンテンツ → **「応答 ID」** を選ぶ

### 4. ＋新しいステップ → Office 365 Outlook「メールの送信 (V2)」
- **宛先**：自分のアドレス
- **件名**：`アンケート回答がありました`
- **本文**：下を貼り、`〔ここ〕` に **式** を入れる

```
アンケートに回答がありました。
受付日：〔ここに式〕
```

`〔ここ〕` に入れる式（本文内で「式」タブ → 貼り付け → OK）：

```
convertTimeZone(utcNow(),'UTC','Tokyo Standard Time','yyyy年M月d日')
```

### 5. 保存

## メモ

- 本文の日付は `utcNow()`（＝受付時刻）にしている。Formsの実際の送信日時を使いたい場合は、
  当日 Copilot に「`応答の詳細`の送信日時を使う式にして」と頼めば差し替え可能（まさに STEP3 の実演ネタ）。
- 完成フローは**別タブで開いておき、答え合わせ用**に。投影は新規フローを作りながら（受講生も一から）。

## 配布用Zipの作り方（ソリューション経由・実機確認済み 2026-06-25）

「エクスポート」直下のZipは環境によって出せないので、**ソリューションごとエクスポート**する。

1. **新しいソリューションを作る**　`ソリューション` → 「新しいソリューション」
   - 表示名 / 名前：任意（例 `PA45No16flow`）
   - 公開元：**PA45 (pa45)** を選ぶ（既定の発行者やCDS Default Publisherは避ける）
   - バージョン：`1.0.0.0` のまま → 作成
2. **フローを入れる**　ソリューションを開く → 「既存を追加」→ 自動化 → クラウド フロー → `PA45-No16-CopilotAssist`
3. **エクスポート開始**　⚠️ 中身の画面には無い。**ソリューション一覧で行を選択**して「エクスポート」
4. **エクスポート前**　「公開」→「次へ」（「展開プロセス／パイプライン」は無視）
5. **不足している接続参照**　Microsoft Forms / Office 365 Outlook を **✓のまま「追加」**（受け取った人が自分の接続を割り当てられる）
6. **アンマネージド**を選ぶ → エクスポート → **Zipダウンロード**
7. ZIPを展開すると中に JSON があり、**Copilotに貼って「何してる？」**と聞ける（STEP4と同じ）

> ⚠️ 黄色い「この環境への現在の特権が不十分」警告が出ても、エクスポートは通ることが多い。
> 押せない時だけ、Power Platform 管理センターで自分に「**システム カスタマイザー**」ロールを付与（管理者操作）。

## 補足：自動構築を試した結果（2026-06-25）

Chrome操作での自動構築を2回試行。フロー作成・Formsトリガー設置までは成功したが、
新デザイナーの設定パネルが iframe 内で安定描画されず（スクショも `document_idle` 待ちで固まる）、
フォーム選択・式入力まで自動で完走できなかった。→ 本ガイドの手動手順での構築を推奨。
