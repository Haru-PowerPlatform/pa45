★ 実演① EXPRESSION

式を書かせる ── convertTimeZone をことばで

Let AI write it

頼み方のコツ

  • やりたいことを書く（UTC→日本時間に）
  • 使う場所を伝える（Power Automateの式）
  • 出力形式を指定（yyyy/MM/dd HH:mm）

※Vol.15で手で書いた式が、頼むだけで出てきます。

🙂
あなた
Power Automateの式で、UTCの日時を日本時間に直して「yyyy/MM/dd HH:mm」で表示したい。式だけ教えて。
🤖
Copilot
これでOKです👇
convertTimeZone(triggerOutputs()?['body/Created'],'UTC','Tokyo Standard Time','yyyy/MM/dd HH:mm')
そのまま貼って動く。 引数の順番を覚えていなくても、日本語で頼めば正しい形で返ってきます。（項目名は自分のフローに合わせて直す）

★ 実演② FIX ERROR

エラーを貼って直してもらう ── 赤い文字をそのまま

Debug with AI

やること

フローが赤くなったら、エラーメッセージを コピーしてそのまま貼る。「これ何が悪い？どう直す？」と聞くだけ。

貼ると伝わること

  • どのアクションで／どんな種類のエラーか
  • よくある原因（綴り・型・空っぽ）
🙂
あなた
Power Automateでこのエラーが出ました。原因と直し方を教えて：
InvalidTemplate: The template language expression ... cannot be evaluated
🤖
Copilot
式のカッコか項目名のズレが原因のことが多いです。まず 項目名が実際の出力と一致しているか確認を。修正版はこちら👇 …
ポイント： エラー文は 消さずに残す。AIにとっては最高のヒント。「全文＋やりたいこと」をセットで貼るのがコツ。

★ 実演③ READ JSON

JSONを読ませる ── 値の取り出し方を聞く

Vol.14の続き

やること

実行履歴の 出力JSONをコピーして貼り、「申請者の名前を取り出す式は？」と聞く。Vol.14でやった「読み方」をAIに任せます。

{ "responder": { "name": "山田 太郎", "email": "yamada@..." } }
🙂
あなた
このJSONから「名前」を取り出すPower Automateの式を教えて。アクション名は「Forms_応答」です。（JSONを貼る）
🤖
Copilot
「responder の中の name」なので👇
outputs('Forms_応答')?['body/responder/name']
動的コンテンツに出ない値も、これで取り出せます。
つながり： Vol.14「JSONの読み方」→ 今日は 読み方ごとAIに聞く。階段を1段ラクに上がれます。

★ THINK DEEPER

難しい式は「じっくり考えて」 ── 配列・条件つき

For hard ones

Think Deeper とは

ふつうの返事より 時間をかけてじっくり考えてもらうモード。配列の絞り込みや 複数条件など、ひとひねりある式に向いています。

  • 「複数の項目をまとめたい」
  • 「条件に合う行だけ残したい」（filter）
  • 「金額を合計したい」
🙂
あなた
（Think Deeper）この配列から「ステータスが承認済の行」だけ残す式を、Power Automate用に作って。理由も短く。
🤖
Copilot · Think Deeper
filter を使います👇
filter(変数, item()?['status'] == '承認済')
各行を見て条件に合うものだけ残す、という意味です。
使い分け： 短い式はふつうのCopilotで即答／ひとひねりあるものはThink Deeper。迷ったら両方に聞いて見比べてもOK。

★ 今日の山場 ／ PROMPT

うまく頼む3つのコツ ── これだけ覚えて帰る

Prompt tips
1

やりたいこと＋材料を一緒に貼る

「日本時間に直したい」だけでなく、対象の式やJSONも一緒に。材料があるほど答えが正確に。

2

出力形式を指定する

「式だけ」「表で」「yyyy/MM/dd で」など、欲しい形を先に言う。やり直しが激減。

3

役割を与える

「Power Automateの先生として初心者向けに」と一言。専門用語を噛み砕いてくれる。

おすすめテンプレ： 「Power Automate初心者です。〔やりたいこと〕。〔材料を貼る〕。〔式だけ／表で〕教えて。」 ── この型に当てはめるだけ。

★ HANDS-ON

いっしょにやってみよう ── 聞き方の通し

Let's try
  • ① AIチャットを開く（M365 Copilot 等）
  • ② テンプレ「初心者です。〜したい。式だけ教えて」
  • ③ convertTimeZone の式を頼んでみる
  • ④ 返ってきた式をフローに貼って動作確認
  • ⑤ 実行履歴のJSONを貼って「名前の取り出し方は？」
  • ⑥ わざとエラーを出して、貼って直してもらう
  • ⑦ 難しいのは Think Deeper で聞き直す
  • ⑧ 「これ便利！」を #PA45 に投稿🎉
⚠️ つまずきポイント： ①答えがズレる→材料が足りない（式・JSONも貼る）。②項目名が違う→自分のフローの実際の出力に直す。③そのまま信じない→必ず実行して確かめる。

PA45｜第16回 ／ 大切なこと

使うときの注意 ── ここだけは守ろう

Cautions
🔒

機密データを貼らない

個人情報・社外秘・実在のメアドはチャットに入れない。サンプル値に置き換えてから相談。

✅

生成物は必ず検証

AIの式も 間違うことがある。そのまま信じず、実行して確かめてから本番へ。

🏢

会社の設定を確認

テナントによっては Copilotがオフのことも。使えない時は管理者に相談を。

合言葉： AIは すごく頼れる下書き役。でも 最後に確かめるのは自分。この2つを守れば、安心して毎日の味方にできます。
