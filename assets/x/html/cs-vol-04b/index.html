この3ステップで足せる
1
Knowledge の「＋」を押す
Build タブの右パネル。
最初はWeb検索だけが入っています
2
資料をドラッグして入れる
PDF・Word・Excel・PowerPoint。
SharePoint や OneDrive から選んでも可
3
名前と"説明"を書いて追加
説明はできるだけ具体的に。
AIがどの資料を見るか選ぶ手がかりに
公式で確認できた仕様
読める形式は幅広い
Word・Excel・PowerPoint・PDF・テキスト・CSV ほか
1ファイル 512MB まで
1エージェントに最大500ファイルまで追加できる
権限は引き継がれる
SharePointは、その人が見られる資料からしか答えない
⚠ 使う前に確認
画像・動画・音声そのものは読めない（PDF内の画像はOK）。パスワード保護や暗号化されたファイルも不可。
