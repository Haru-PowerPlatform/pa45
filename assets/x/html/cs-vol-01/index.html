前編 (1/2)
Power Automate は"作業ロボ"、
Copilot Studio は"考える受付係"！
結論
Power Automate＝決めた手順を自動でくり返す。Copilot Studio＝会話して自分で考えて動く。
役割がちがうので、場面に合わせて"使い分け"るのが正解です。
Power Automate
🦾決めた手順どおりに動く"作業ロボ"
  • トリガー → アクションの「決まった流れ」を自動で実行
  • 同じ作業を、速く・正確に・なんども くり返す
  • その場の判断は入らない（決めた手順どおり）
  • 例メールが来たら、添付ファイルを自動で保存
Copilot Studio
💬会話して自分で考える"AIアシスタント"
  • 自然な言葉で質問に答え、相手と対話する
  • 状況に応じて、自分で判断してアクションする
  • 社内文書（ナレッジ）を読み込んで回答できる
  • 例社内のよくある質問に答えるAIを作る
VS
じつは組み合わせて使える！
Copilot Studio ＋ Power Automate
Copilot Studio の中から PA の自動化（エージェント フロー）も呼べる＝合わせ技OK
使い分けのコツ
決まりきった作業 → Power Automate
会話・判断が要る → Copilot Studio
