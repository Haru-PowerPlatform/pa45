もう"台本"は書かない！
新しい Copilot Studio は AI が段取りを組む
結論
生まれ変わった Copilot Studio は「新オーケストレーター」を搭載。
会話の分岐（台本）を人が設計するのでなく、ゴールと道具を渡せば段取りは AI が自分で組みます。
これまで：台本（トピック）方式
🎭台本どおりに動く"新人スタッフ"
  • 会話の分岐（トピック）を人間がぜんぶ設計
  • 台本にない質問には「すみません、わかりません」
  • 質問が増えるたびに、分岐を追加・修正
  • つらいまとめて3つ聞かれたら、もうお手上げ
これから：新オーケストレーター
🧠ゴールから段取りを組む"ベテラン受付"
  • 渡すのは指示文（ゴール）と道具だけ
  • 複数の質問も、自分で分解して順に回答
  • ナレッジを検索するかどうかも自分で判断
  • 実測指示文4行で、3つの質問に出典付きで回答
進化
実機でこう動きました（PA45 Demo）
質問を3つに分解 → ナレッジを検索 → 出典付きで回答
