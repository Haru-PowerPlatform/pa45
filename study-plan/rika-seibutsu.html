🫀 理科Ⅱ 動物の体のはたらき

消化と吸収／呼吸／血液の循環／不要な物質の行方　まとめ・図・問題
①消化と吸収 ②呼吸 ③血液の循環 ④不要物の行方

① 栄養分を取り入れる（消化と吸収）

食べ物は大きいままでは体に取りこめない。小さな養分に分解（＝消化）してから吸収する。

🍽 消化の道すじ

▲ 口→食道→胃→小腸→大腸→肛門。肝臓・胆のう・すい臓から消化液が小腸へ出る。

🧪 消化液と消化酵素

消化液出る所はたらき
だ液だ液せんアミラーゼ → デンプンを分解
胃液胃ペプシン → タンパク質を分解
すい液すい臓デンプン・タンパク質・脂肪すべてに働く
胆汁肝臓
（胆のうにためる）		消化酵素はない。脂肪を細かくして消化を助ける
🎯 最後にできる養分：デンプン→ブドウ糖／タンパク質→アミノ酸／脂肪→脂肪酸とモノグリセリド。

🌱 吸収のしくみ（小腸の柔毛）

▲ 小腸の内側は柔毛だらけ＝表面積が大きく、効率よく吸収できる。
どこへ運ばれる？ ブドウ糖・アミノ酸→柔毛の毛細血管へ。脂肪酸・モノグリセリド→柔毛で再び脂肪になりリンパ管へ。
柔毛がたくさんある理由＝表面積を大きくして、養分を効率よく吸収するため。

🔬 だ液のはたらきの実験

デンプンのり＋だ液を約40℃（体温くらい）であたためる。
・ヨウ素液（デンプンがあると青紫）→変化しない＝デンプンが分解された
・ベネジクト液＋加熱（糖があると赤かっ色）→赤かっ色＝糖ができた
※水を入れたほうと比べる（対照実験）。だ液でデンプン→糖になったとわかる。
✏️ 問題（消化と吸収）
  1. デンプン・タンパク質・脂肪は、最後にそれぞれ何に分解される？
  2. だ液にふくまれる消化酵素の名前は？ 何を分解する？
  3. 胆汁の特ちょうを「消化酵素」という言葉を使って説明しよう。
  4. 小腸の内側にある小さな突起を何という？ たくさんある理由は？
  5. だ液の実験で、ヨウ素液とベネジクト液はそれぞれ何を調べる薬品？
1. デンプン→ブドウ糖／タンパク質→アミノ酸／脂肪→脂肪酸とモノグリセリド
2. アミラーゼ。デンプンを分解する
3. 胆汁は消化酵素をふくまないが、脂肪を細かくして消化を助ける
4. 柔毛。表面積を大きくして養分を効率よく吸収するため
5. ヨウ素液＝デンプンがあるか（青紫）／ベネジクト液＝糖があるか（赤かっ色）

② 動物の呼吸

🫁 肺のつくりとガス交換

気管 → 気管支 → その先に肺胞（はいほう）という小さな袋がたくさん。肺胞のまわりを毛細血管がとり囲む。

▲ 肺胞で、空気中の酸素を血液へ取りこみ、血液中の二酸化炭素を出す（ガス交換）。
肺胞がたくさんある理由 空気とふれる表面積が大きくなり、効率よくガス交換できるから。（小腸の柔毛と同じ考え方！）

💨 呼吸運動（息を吸う・はく）

肺には筋肉がない。ろっ骨と横隔膜（おうかくまく）の動きで空気を出し入れする。

息を吸うとき息をはくとき
横隔膜下がる上がる
ろっ骨上がる下がる
胸の空間広がる→肺ふくらむせまくなる→肺ちぢむ

🔥 細胞による呼吸（細胞呼吸）

体の細胞が、運ばれてきた酸素を使って養分を分解し、エネルギーを取り出すはたらき。
このとき 二酸化炭素と水ができる。（養分 ＋ 酸素 → エネルギー ＋ 二酸化炭素 ＋ 水）
✏️ 問題（呼吸）
  1. 気管支の先にある、小さな袋を何という？
  2. 肺胞がたくさんあると、なぜ都合がいい？
  3. 息を吸うとき、横隔膜とろっ骨はそれぞれどう動く？
  4. 細胞が酸素を使って養分を分解し、エネルギーを取り出すことを何という？ そのとき何ができる？
1. 肺胞
2. 表面積が大きくなり、効率よくガス交換ができるから
3. 横隔膜は下がり、ろっ骨は上がる（→胸の空間が広がって肺がふくらむ）
4. 細胞による呼吸（細胞呼吸）。二酸化炭素と水ができる

③ 物質を運ぶ（血液の循環）

🫀 心臓のつくり

心臓は血液を送り出すポンプ。中は4つの部屋（2心房・2心室）に分かれている。

▲ 心臓は2心房2心室。青＝二酸化炭素が多い血液、赤＝酸素が多い血液。

🩸 血液の成分

成分はたらき
赤血球ヘモグロビンが酸素を運ぶ
白血球体に入った細菌をやっつける
血小板出血を止める
血しょう液体。養分・二酸化炭素・不要物を運ぶ

※血しょうの一部が血管からしみ出したものを組織液といい、血液と細胞の間のやりとりを仲立ちする。

🔁 2つの血液の循環

▲ 肺循環：心臓→肺→心臓。体循環：心臓→全身→心臓。
⚠️ ひっかけ注意！ 動脈血＝酸素が多い血液、静脈血＝二酸化炭素が多い血液（血管の名前ではなく中身のこと）。
肺動脈には静脈血、肺静脈には動脈血が流れる（名前と中身が逆になる！）。
✏️ 問題（血液の循環）
  1. 心臓の4つの部屋の名前をすべて答えよう。
  2. 酸素を運ぶ血液の成分と、その中の物質の名前は？
  3. 「心臓→肺→心臓」「心臓→全身→心臓」の循環をそれぞれ何という？
  4. 動脈血と静脈血のちがいは？
  5. 肺動脈に流れているのは動脈血・静脈血のどっち？
1. 右心房・右心室・左心房・左心室
2. 赤血球。中のヘモグロビンが酸素を運ぶ
3. 心臓→肺→心臓＝肺循環／心臓→全身→心臓＝体循環
4. 動脈血＝酸素が多い／静脈血＝二酸化炭素が多い
5. 静脈血（肺動脈は名前と中身が逆）

④ 不要な物質の行方（排出）

細胞のはたらきで出たいらない物質を、体の外に出すしくみ。

不要な物質どこから出す？
二酸化炭素血液→肺→体外
アンモニア（有害）肝臓で害の少ない尿素に変える → じん臓でこしとる → 尿

🫘 じん臓と排出のしくみ

▲ じん臓が血液から尿素などをこしとって尿をつくる → 輸尿管 → ぼうこう → 体外。
🏭 肝臓のはたらき（まとめ）
① アンモニア → 尿素に変える　② 養分（ブドウ糖）をたくわえる　③ 有害な物の解毒　④ 胆汁をつくる
✏️ 問題（不要物の行方）
  1. 有害なアンモニアは、どこで何に変えられる？
  2. 尿素は、どこでこしとられて尿になる？
  3. じん臓でできた尿は、どこを通ってどこにためられる？
  4. 肝臓のはたらきを2つ書こう。
1. 肝臓で、害の少ない尿素に変えられる
2. じん臓でこしとられて尿になる
3. 輸尿管を通ってぼうこうにためられる
4. （例）アンモニアを尿素に変える／養分をたくわえる／解毒する／胆汁をつくる　など2つ
まちがえた問題は、答えを見たあとにもう一度自分で答えてみよう✍️
教科書の図（消化管・肺胞・心臓・じん臓）と、細かい用語（柔毛・ヘモグロビン・尿素 など）まで覚えると強い💪
