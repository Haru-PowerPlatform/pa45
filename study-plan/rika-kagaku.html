① 実験2「水（H2O）の電気分解」

実験ノートの内容はテストによく出ます。手順より「何が・どこに・どうやってできたか」を覚えよう。

🔬 何をした実験？

うすい水酸化ナトリウム水溶液に電気を流して、水を分解した実験。

なぜ水酸化ナトリウムを入れるの？ 純粋な水（H2O）だけだと電流がほとんど流れない。だから電流を流れやすくするために少しだけ加える。水酸化ナトリウムは反応の主役ではない（水が分解されるのが主役）。

🖼 実験のようす（装置の図）

▲ 水の電気分解の装置。陰極（−）に水素・陽極（＋）に酸素がたまり、水素のほうが2倍多い。

⚡ 結果（ここが超だいじ）

陰極（−極）陽極（＋極）
出る気体水素 H2酸素 O2
確かめ方マッチの火を近づけると
ポッと音を立てて燃える		火のついた線香を入れると
炎を上げて激しく燃える
体積多い（2）少ない（1）
📏 体積比は 水素：酸素＝2：1。陰極の水素のほうが2倍多い。
覚え方：「陰極（マイナス）＝水素＝2倍」。水（H2O）のHが2つ・Oが1つ、と同じ比！

🧪 化学反応式

2H2O → 2H2 ＋ O2

（水が分かれて、水素と酸素になる。左右で原子の数が同じ＝H:4個・O:2個）

✏️ 問題（水の電気分解）
次の問いに答えよう。
  1. 陰極（−極）に出る気体は何？　陽極（＋極）は？
  2. 水素が出たことを確かめる方法は？
  3. 酸素が出たことを確かめる方法は？
  4. 水素と酸素の体積の比は？
  5. この実験の化学反応式を書こう。
  6. なぜ水酸化ナトリウムを少し加える？
1. 陰極＝水素、陽極＝酸素
2. マッチの火を近づけるとポッと音を立てて燃える
3. 火のついた線香を入れると炎を上げて激しく燃える
4. 水素：酸素＝2：1
5. 2H2O → 2H2 ＋ O2
6. 純粋な水は電流が流れにくいので、電流を流れやすくするため（水酸化ナトリウム自体は分解の主役ではない）

② 実験6「鉄と硫黄の反応」

🔬 何をした実験？

鉄（Fe）の粉と硫黄（S）を混ぜて加熱すると、別の物質硫化鉄（FeS）ができる。

加熱は最初だけ！ 上のほうを少し加熱して赤くなったら火を止める。加熱をやめても、反応で出た熱で反応がどんどん下へ続く（＝熱が出る「発熱反応」だから）。

🖼 実験のようす（加熱の図）

▲ 鉄と硫黄の混合物を試験管で加熱。上のほうが赤くなったら火を止めても、発熱で反応が下へ続く。

🧪 化学反応式

Fe ＋ S → FeS

⚖️ 反応の前と後をくらべる（テスト頻出）

「別の物質になった」と言える理由を、2つの実験で確かめる。

（硫化鉄 FeS）
磁石を

磁石につく		磁石につかない
（別の物質になった）

🔑 「磁石につくか」「塩酸でどんなにおいの気体が出るか」で、反応前と後が別の物質だと分かる。
✏️ 問題（鉄と硫黄）
  1. 鉄と硫黄を加熱してできる物質の名前と化学式は？
  2. 化学反応式を書こう。
  3. 加熱をとちゅうでやめても反応が続くのはなぜ？
  4. 反応後の物質に磁石を近づけるとどうなる？
  5. 反応後の物質にうすい塩酸をかけると、どんなにおいの気体が出る？その気体の名前は？
1. 硫化鉄（FeS）
2. Fe ＋ S → FeS
3. 熱が出る反応（発熱反応）なので、その熱で次々と反応が進むから
4. 磁石につかない（反応前はついた＝別の物質になった証拠）
5. 卵のくさったようなにおい。気体は硫化水素

③ 化学反応式の書き方（係数のつけ方）

「数字（係数）をどうつければいいか分からない」を、ここで完全攻略！

🧠 いちばん大事なルール：化学反応式は、矢印（→）の左と右で、原子の種類と数が同じでなければならない。
（原子は急に消えたり生まれたりしない。形が変わるだけ。）
⚠️ ここを間違えやすい！ 数を合わせるのは、化学式の前につける大きい数字（＝係数）だけ。
化学式の中の小さい数字（H2O の「2」など）は、ぜったいに変えてはいけない！
（小さい数字を変えると、別の物質になってしまうから。）

📝 4ステップでできる

反応する前の物質と、できる物質を、化学式で書く（まだ係数はつけない）。
矢印の左と右で、原子を種類ごとに数える。
足りないほうに係数（前の大きい数字）をつけて、左右の数を合わせる。小さい数字はさわらない。
係数が「1」のときは書かない。これで完成！

💧 例：水素＋酸素 → 水

まず係数なしで書くと…

H2 ＋ O2 → H2O
左がわ
H＝2こ／O＝2こ
右がわ
H＝2こ／O＝1こ

Oが「左2・右1」で合わない → 右の水に係数2をつける：

H2 ＋ O2 → 2H2O
左がわ
H＝2こ／O＝2こ
右がわ
H＝4こ／O＝2こ

今度はHが「左2・右4」で合わない → 左の水素に係数2：

2H2 ＋ O2 → 2H2O
左がわ
H＝4こ／O＝2こ
右がわ
H＝4こ／O＝2こ

✅ 左右ピッタリ！完成： 2H2 ＋ O2 → 2H2O

コツ：O2 のように「2個セット」の気体があると、奇数だと合わない そういうときは全体を2倍すると合うことが多い。
例：アルミ 2Al＋3/2O2→Al2O3 は分数が出る → 全部2倍して 4Al＋3O2→2Al2O3（はるきがノートでやっていた通り！）
✏️ 問題（係数を入れて完成させよう）
□に入る係数を答えよう（1のときは「1」と書く）。
  1. □Mg ＋ □O2 → □MgO
  2. □Cu ＋ □O2 → □CuO
  3. □H2 ＋ □O2 → □H2O
  4. Fe ＋ S → □（できる物質を書こう）
  5. □Al ＋ □O2 → □Al2O3
  6. （チャレンジ）□H2O → □H2 ＋ □O2（水の電気分解）
1. 2Mg ＋ 1O2 → 2MgO
2. 2Cu ＋ 1O2 → 2CuO
3. 2H2 ＋ 1O2 → 2H2O
4. Fe ＋ S → FeS
5. 4Al ＋ 3O2 → 2Al2O3
6. 2H2O → 2H2 ＋ 1O2
※係数の「1」はふだんは書かないよ。

④ 覚えるべき化学式と「なぜその式になるか」

丸暗記の前に「なぜ？」が分かると、忘れにくいし応用がきく。

🤝 カギは「原子の手（うで）の数」。原子には、ほかの原子と手をつなぐ「手の数」が決まっている。
手の数がピッタリ全部つながるように、原子の数が決まる。

✋ おもな原子の手の数

手の数原子（例）
1本水素 H ・ 塩素 Cl ・ ナトリウム Na
2本酸素 O ・ マグネシウム Mg ・ カルシウム Ca ・ バリウム Ba
3本窒素 N ・ アルミニウム Al
4本炭素 C

🔎 例でなっとく

アンモニア NH3 はなぜ「N1個・H3個」？ 窒素 N は手が3本。水素 H は手が1本。
Nの3本の手を、Hが1本ずつ受けもつ → Hが3つ必要 → だから NH3！
　　　H
　　　|
　H －N－H　（Nの手3本 × H1本ずつ）
水 H2O はなぜ「H2個・O1個」？ 酸素 O は手が2本、水素 H は1本。Oの2本の手にHが1本ずつ → Hが2つ → H2O。
二酸化炭素 CO2 は？ 炭素 C は手が4本、酸素 O は2本。Cの4本を、O（2本）が2個で受けとる → CO2。
メタン CH4 は？ 炭素 C は手が4本、水素 H は1本。Cの4本にHが1本ずつ → Hが4つ → CH4。

✏️ 問題（化学式となぜ）
  1. 窒素 N の手の数は何本？　だから水素 H と結びつくとHはいくつでアンモニアはNH□？
  2. 炭素 C の手の数は？　だからメタンの化学式は？
  3. 次の化学式を書こう：①水　②二酸化炭素　③酸素　④硫化鉄　⑤酸化銅
  4. 「酸素 O の手は2本」を使って、水が H2O になる理由を説明しよう。
1. Nの手は3本。Hが3つで NH3
2. Cの手は4本。だから CH4
3. ①H2O　②CO2　③O2　④FeS　⑤CuO
4. 酸素の2本の手に、手が1本の水素が1本ずつ・2つつながるから H2O

⑤ ( )カッコの意味　— Ba(OH)2 って何？

📦 カッコ＝「まとまり」が何個あるかを表す。
カッコのすぐ右下の数字は、カッコの中身ぜんぶにかかる。

🔎 例：水酸化バリウム Ba(OH)2

OH（酸素O1個＋水素H1個の「まとまり」）が、2個あるという意味。

Ba(OH)2 の中身
Ba＝1こ／O＝2こ／H＝2こ
⚠️ なぜカッコが要るの？ もしカッコをつけず BaOH2 と書くと、「Hだけが2個」というちがう意味になってしまう。
OH のまとまりごと2個にしたいので、(OH) でくくって右下に2 と書く。
手の数で考えると… バリウム Ba は手が2本。OH は1本の手を持つまとまり。
Baの2本の手に、OH（1本）が2つつながる → Ba(OH)2。④の考え方と同じ！

🔎 例：炭酸アンモニウム (NH4)2CO3

NH4（アンモニウムというまとまり）が2個＋ CO3 が1個。

(NH4)2CO3 の中身
N＝2こ／H＝8こ／C＝1こ／O＝3こ

※ NH4 が2個なので、N＝1×2＝2、H＝4×2＝8。カッコの2が中身全部にかかる。

✏️ 問題（カッコの意味）
  1. Ba(OH)2 の中に、O とH はそれぞれ何個ある？
  2. (NH4)2CO3 の中に、H は何個ある？
  3. 水酸化カルシウム Ca(OH)2 の中の、Ca・O・H の数を答えよう。
  4. Ba(OH)2 のカッコをなくして BaOH2 と書くと、どこが変わってしまう？
1. O＝2個、H＝2個（OHが2まとまり）
2. H＝8個（NH4 の H4個 ×2まとまり）
3. Ca＝1個、O＝2個、H＝2個
4. Hだけが2個になってしまい、OHのまとまりが2個という意味が消える（別物になる）
まちがえた問題は、答えを見たあとにもう一度自分で書いてみよう✍️
