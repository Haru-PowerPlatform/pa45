③ バイラル試用版＝「作れる」けど「動かす」と止まる

この節で分かること
バイラル試用版で詰まる場所を見ます。
読み終えるとこうなる
止まったときの原因が分かります。

Copilot Studio の無料試用版で、実際にできたこと・止まったことを分けると、こうなります。

やったこと結果
エージェントを作る／指示文・ナレッジ・ツールを設定するできる
Teamsに公開する・Previewで会話する（軽いもの）おおむねできる
フロー（自律・AIアクション）を実行する止まる

フローを実行しようとしたとき、エラーはこう出ました。

Flow returned HTTP 403.
InnerErrorCode: InsufficientMcsCredits

原因はクレジット不足（InsufficientMcsCredits）でした。バイラル試用版には、実行のためのクレジット容量が付いていません。
だから「作る・設定する」まではできても、「フローやAIを実際に動かす」段で止まります。
これは指示文や作りのミスではなく、環境（ライセンス容量）の問題です。
ここを取り違えると、直さなくていい設定を直しに行くことになります。
Copilot Studio の料金・クレジットの仕組みは Copilot Studioは“使うほど課金”される にまとめています。実際に動かすには、従量課金（pay-as-you-go）か容量パックでクレジットを用意する必要があります。
 
作るところまでは無料でいけて、動かす段で止まることがあります。
「作れる＝使える」ではない、と知っておくと戸惑いにくいです。

④ Microsoft 365 Copilot ライセンスが開くもの

この節で分かること
M365 Copilot ライセンスで開くものを見ます。
読み終えるとこうなる
何を足せば動くのかが分かります。

もうひとつ分かったのは、Microsoft 365 Copilot ライセンス（Copilot Studio の試用版とは別）があると、開く機能があることです。

具体的には、社内資料（SharePoint など）を、その人の権限で検索して根拠にする機能（テナントグラフの根拠 ／ セマンティック検索）です。
これは Microsoft 365 Copilot 側のライセンスに関わる機能で、Copilot Studio の実行クレジットとはまた別枠です。

「使えない」には2種類ある

フローが実行できない
Copilot Studio のクレジット不足（InsufficientMcsCredits）。従量課金か容量パックでクレジットを足すと動きます。
社内データを根拠にできない
Microsoft 365 Copilot ライセンスの話。SharePoint などを根拠にする機能はこちらに関わります。
「ライセンスが無い」と「クレジットが無い」は別物同じ「使えない」でも、①社内データ系＝Microsoft 365 Copilot ライセンスの話、②フロー実行＝Copilot Studio のクレジットの話、と原因が分かれます。
両方を「ライセンスが足りない」で一括りにすると、対処を間違えます。何が足りなくて止まっているのかを、まず切り分けるのが早道です。
