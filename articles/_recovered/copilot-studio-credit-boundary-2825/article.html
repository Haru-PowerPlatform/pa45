② 公式の答え：「読む・答える」はゼロ評価

この節で分かること
読む・答えるがゼロ評価になる根拠を確認します。

無償で使える範囲が分かります。

Microsoft の課金ドキュメント（標準ハーネスのライセンス・2026年8月時点）に、はっきり書かれていました。

Microsoft 365 Copilot ライセンスをお持ちの場合、Copilot Chat、Microsoft Teams、または SharePoint のエージェントを使用して、クラシックの回答・生成回答・Microsoft Graph テナントの基礎づけ（tenant grounding）を行うことは、Copilot Studio のメッセージパックやメーターにカウントされません（ゼロ評価の使用状況になります）。

つまり、Microsoft 365 Copilot ライセンスがあれば、次の3つはゼロ評価（無償）です。

  • 定型回答（classic answers）
  • 生成回答（generative answers）
  • 社内データの検索（Microsoft Graph テナント根拠）＝いわゆる Work IQ 相当
言いかえると、「答える・読む・社内資料を検索する」は、ライセンスの範囲で課金されない。
だから、クレジットが 0 の環境でも、これらは動きます。
実際に、社内資料の検索が通ったのはこのためでした。
 
読む・答えるはゼロ評価、というのが公式の線でした。
ここを押さえると、どこから費用がかかるかの見当がつきます。

操作種類ライセンスで無償？
定型回答答える無償（ゼロ評価）
生成回答答える無償（ゼロ評価）
社内資料の検索（テナント根拠）読む無償（ゼロ評価）
ツール／フローの実行（エージェントのアクション）実行する消費する
自律トリガーの起動実行する消費する（重い）

今回 403 で止まった「質問を記録する」は、まさにツール（フロー）の実行＝エージェントのアクションでした。
ここは無償の対象外なので、クレジットが要る。
クレジットが 0 の環境（無料の試用版など）では、必ずここで止まります。

壁を生んでいるのは「実行する」系だけ。
「読む・答える」はライセンスで越えられる——今回の非対称は、この線引きどおりでした。

誤解したまま人に説明せずに済みます。
「無償」には条件があるこの無償（ゼロ評価）は、Microsoft 365 Copilot ライセンスを持つユーザーが、Copilot Chat・Teams・SharePoint といった Microsoft 365 の場でエージェントを使うときの話です。

※ 「実行系」を動かすには

ツール実行・フロー・自律トリガーを実際に動かすには、Copilot Studio のクレジットが必要です。
従量課金（使った分だけ）か、前払いの容量パックで用意します。
無料の試用版にはクレジットが付いていないので、実行系は止まります。
料金の全体像は Copilot Studioは“使うほど課金”される、学習環境（試用版で何ができて何で詰まるか）は Copilot Studioを学ぶ“テスト環境”の話 にまとめています。

※ 2026年8月21日の追記：いつも止まるわけではない

同じ構成のフロー実行を別の日に試したところ、403 は出ず、最後まで動きました。
前払いクレジットの残量は 0 のままで、消費レポートの数字もその日は増えていません。
猶予期間や枠の扱いによって挙動が変わるようです。
「クレジットが無いから実行系は必ず止まる」とは考えず、動く前提で費用を見積もるほうが安全です。

まとめ

  • 読む・答える（定型/生成回答・社内データ検索）＝ M365 Copilot ライセンスでゼロ評価（無償）
  • 実行する（ツール/フロー・自律トリガー）＝ クレジットを消費する
  • 壁を生むのは「実行系」だけ。
    読む・答えるはライセンスで越えられる
  • クレジット0の環境では、実行系だけが 403（InsufficientMcsCredits）で止まる

「クレジットが足りない」と「ライセンスが足りない」を混ぜて考えると、対処を間違えやすくなります。その操作は"読む・答える"か、"実行する"か。
