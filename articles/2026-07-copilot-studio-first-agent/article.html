全体の構成：書くのは名前と指示だけ

題材は、勉強会の参加希望者からの質問に答える受付役です。
どんな会か、初めてでも参加できるか、といった質問に文章で答える状態を目指します。

エージェントの中身は、左の名前と指示、右のモデル・ナレッジ・ツールなどに分かれています。
右側は、作った直後から入っているものをそのまま使います。

用語
エージェント：質問を受けて、自分で調べ方を決めて答える AI。
Copilot Studio では、指示の文章と、持たせる部品（ナレッジやツール）を組み合わせて作る。

PA45 は、筆者が運営している Power Automate の無料オンライン勉強会です。
題材は、社内の FAQ など身近なものに置き換えても同じ手順で作れます。

② 名前と指示を書く

名前は「無題のエージェント」になっていて、文字が選ばれた状態で開きます。
指示の欄には、書き方の説明と例が薄い文字で出ています。

2-1名前を入れる
  1. 名前の欄を押す（開いた直後は、すでに選ばれている）
  2. 分かる名前に書き換える（例：勉強会の受付エージェント）
2-2指示を書く
  1. 「指示」の下の、薄い文字が出ている場所を押す
  2. 下の文を入れる（自分の題材に合わせて書き換える）
あなたは「PA45」という Power Automate 勉強会の受付エージェントです。 参加者からの質問に日本語で丁寧に答えます。 PA45 は毎週木曜の夜に開催する、参加無料・初心者歓迎のオンライン勉強会です。 わからないことは「わからない」と答え、推測で断言しません。
用語
指示：エージェントに、役割と答え方を伝える文章。
画面の説明では、役割と目標、対応する範囲、口調、質問やナレッジを使うタイミングを書くとある。

4行は、次の4つに対応させています。

行書いたことこの記事の例
1行目役割勉強会の受付エージェント
2行目口調日本語で丁寧に
3行目答える範囲の材料開催日・参加費・対象
4行目わからないときの対応わからないと答え、推測で断言しない
なぜそうするか4行目を入れたのは、指示に書いていないことを聞かれた場合のためです。
ナレッジに Web 検索が入っているので、書いていないことは Web の情報で答えようとします。
勉強会の中身のように Web に無い情報は、わからないと返すほうが安全だと考えました。

③ 保存する

3-1保存のアイコンを押す
  1. 右上に並ぶアイコンのうち、フロッピー ディスクの形の「保存」を押す（Ctrl + S でも同じ）
  2. 上に「エージェントを保存しています」と出る
  3. しばらくして、緑の帯で「エージェントが保存されました。」に変わる

この環境では、保存が終わるまでに20秒ほどかかりました。
保存すると、評価と監視のタブも押せるようになります。

④ プレビューで試す

4-1プレビューのタブで質問を送る
  1. 上のタブを「作成」から「プレビュー」に切り替える
  2. 下の入力欄（Message …と薄く出ている欄）に質問を書く
  3. Enter を押して送る
初参加を考えています。PA45 がどんな会か教えてください。 まったく触ったことがなくても参加できるか、準備するものもあわせて教えてください。
クレジットが無いと、プレビューでも会話できない撮影した日は、環境の Copilot クレジットが 0 でした。
プレビューを開くと、You need credits to continue. というメッセージが出て、会話は始まりません。
エラー コードは EnforcementUsageCredits でした。
作成と保存はクレジットが無くてもできましたが、試すにはクレジットが要ります。

下は、クレジットがあった 2026年7月に、同じ指示で質問したときの画面です。
当時は英語の表示でしたが、答えは日本語で返っています。

1回の質問に3つのことを入れても、分けて順に答えが返りました。
会話の分岐は1つも作っていません。

指示だけでも答えは返りますが、根拠は Web の情報です。
社内の文書に沿って答えさせる場合は、ナレッジに資料を足す形になります。
