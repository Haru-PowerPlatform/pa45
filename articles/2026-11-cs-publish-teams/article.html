この記事では、エージェントを Teams で使えるようにするまでの操作を、実際の画面で1手ずつ載せています。

画面は 2026年11月13日に撮り直しました。

① チャネルの＋を押し、Teams + Microsoft 365 を選ぶ

1-1エージェントを開き、チャネルの＋を押す
  1. copilotstudio.microsoft.com を開き、左メニューの「エージェント」を押す
  2. 一覧から、Teams に出したいエージェントの名前を押す
  3. 作成の画面の右側にある「チャネル」の行の右端の「＋」を押す
1-2Teams + Microsoft 365 を押す
  1. 「チャネルの追加」の画面が開く
  2. 見出しの下に、現在の認証設定で利用できるチャネル、と書かれている
  3. 「Teams + Microsoft 365」を押す

※ デモ Web サイトは、認証なしにすると選べる

デモ Web サイトのカードには、認証なしにする必要があります、という説明が付いていました。
いまの認証の設定のままでは選べない、という意味です。
認証の設定を変えた場合の動きは、この記事では確かめていません。

② 使う場所を選び、説明を書いて追加する

2-1使う場所を選ぶ
  1. 「Microsoft 365 と Microsoft Teams」の画面になる。左に、使用可否・バージョン情報・使用と共有・アプリ マニフェストが並ぶ
  2. 「使用可否」で、2つのうちどちらかを選ぶ
選べるもの使える場所
Microsoft 365 Copilot と Microsoft TeamsMicrosoft 365 Copilot の中と、Teams の両方（最初に選ばれている）
Microsoft Teams のみTeams だけ
この設定は、公開後に変更できない画面に、この設定は公開後に変更できません、と書かれています。
この記事では、範囲の狭い「Microsoft Teams のみ」を選びました。
2-2バージョン情報に説明を書く
  1. 左の「バージョン情報」を押す
  2. 「簡単な説明」（必須・最大80文字）に、何をするエージェントかを書く
  3. 「詳細な説明」（最大3400文字）に、もう少し詳しく書く
  4. 右下の「チャネルを追加」を押す

2つの説明の欄には、最初から英語の文が入っていました。
簡単な説明は Built using Microsoft Copilot Studio. という文です。
開発者名には、サインインしているアカウントの表示名が入っていました。

なぜそうするか英語の既定の文のままだと、何をするエージェントかが伝わらないので、日本語で書き換えました。

④ Teams で使う（初版での記録）

この節の画面は、初版（2026年9月）のときに撮ったもの当時は英語の表示で、エージェントの名前も題材も、いまの手順とは違います。
公開のあとに出る画面の、いまの表示は確かめていません。

初版のときは、公開のあとに Teams で開くためのボタンが出ました。
押すと Teams が開き、エージェントを追加する画面になります。

ナレッジや指示は、そのまま Teams に引き継がれていました。
メールを送るツールも Teams 上で動き、送る前に許可を確認するカードが出ています。
ツールの記録は ツールの付け方 に載せています。

ほかの人に使ってもらう方法

左の「使用と共有」は、チャネルを追加する前の画面では薄い表示でした。
初版のときに確認した配り方は、次の3つです。

配り方内容（初版のときの確認）
リンクを共有するいちばん手数が少ない。モバイルでは開けないことがあった
Teams のアプリ ストアに出す共有された人が、自分で追加して使う
組織用に申請する管理者の承認を受けて、組織全体で使えるようにする

※ グループでは使えないナレッジがある

SharePoint のように、使う人の権限で見に行くナレッジは、チャネルやグループ チャットでは使えず、1対1のチャットだけで動きました。
これは初版のときの確認で、今回は確かめ直していません。
公開の前に、誰に使ってもらうかと、ツールが何をするかを決めておく進め方にしています。
公開したあとで変えられない設定があるためです。
