機能・画面・料金は更新が続きます。

前の記事で、名前と指示だけのエージェントを作りました。
そのエージェントは Web の情報をもとに答えるので、社内の決まりや、勉強会の各回の内容のような情報は答えられません。

この記事では、エージェントに資料を1つ読ませます。
Copilot Studio ではこの資料をナレッジと呼びます。
エージェントの一覧からどこを押して進むかを、実際の画面で1手ずつ載せています。

画面は 2026年11月13日に撮り直しました。
7月に試したときは英語の表示でしたが、いまは日本語の表示になっています。

この記事でわかること

  1. ナレッジを足したあとの構成（指示とナレッジの役割の違い）
  2. エージェントの一覧から、ナレッジの追加の画面までの行き方
  3. ファイルを入れて、名前と説明を書き、準備完了を待つ手順
  4. 追加の前後で答えがどう変わったか、確かめていないこと

全体の構成：指示はそのまま、ナレッジを1つ足す

指示は、どう答えるかを決める部分です。
ナレッジは、何をもとに答えるかを決める部分です。
この記事では指示を1文字も変えず、ナレッジだけを足します。

用語
ナレッジ：エージェントが答えるときに調べる情報源。
ファイル、公開 Web サイト、SharePoint などを登録する。

用意するもの

用意するもの内容
作成済みのエージェントエージェントの作り方 の記事で作ったもの
読ませるファイルWord・PDF・テキストなど。この記事ではテキスト ファイル1つ
Copilot クレジット追加するだけなら不要だった。追加後に会話で試すときに要る

読ませたのは、勉強会の案内をまとめたテキスト ファイルです。
開催日時、対象、準備するもの、申し込み方法、第8回のテーマ、欠席の方法の6項目を書いてあります。

※ 最初は公開してよい資料で試す

アップロードしたファイルは、エージェントを使う人への回答に使われます。
人事評価や個人情報を含む資料は対象から外し、まず公開している案内のような資料で試しました。

③ 名前と説明を書いて、エージェントに追加する

3-1名前と説明を書き換える
  1. 表の「名前」の欄を押し、分かる名前にする（例：PA45 勉強会のご案内）
  2. 「説明」の欄を押し、何が書いてある資料かを具体的に書く
  3. 右下の「エージェントに追加する」を押す
PA45 勉強会の開催日時、対象、準備するもの、申し込み方法、各回のテーマ、欠席の方法。 勉強会への参加に関する質問はこの資料を参照する
なぜそうするか説明は、エージェントがどの資料を調べるかを決める材料になります。
自動で入る説明は、このナレッジ ソースは（ファイル名）に含まれる情報を検索します、という文です。
これでは中身が分からないので、書いてある項目と、どんな質問で使うかを書きました。

④ 状態が「準備完了」になるのを待つ

4-1資料の名前を押して、状態を見る
  1. 右の「ナレッジ」に並んだ資料の名前を押す
  2. 「ナレッジ ソースを編集する」という画面が開く
  3. 右上の「状態」を見る。「処理中」なら、閉じて少し待ってから開き直す

このテキスト ファイル（1KB ほど）では、追加してから数十秒で「準備完了」になりました。
処理中のあいだに質問すると、資料を使わない答えが返ることがあります。

用語
インデックス：資料の中身を、検索しやすい形に整理したもの。
作り終わるまで、エージェントはその資料を調べられない。

※ 保存のボタンは押さなくてよかった

追加したあと、右上の保存のアイコンは押せない状態（薄い表示）になっていました。
ナレッジの追加は、その時点で保存されていると読み取りました。

追加の前と後で、答えはどう変わったか

この節の画面は 2026年7月に撮ったもの撮影した日は環境の Copilot クレジットが 0 で、プレビューの会話ができませんでした。
下の3枚は、クレジットがあった7月に、別のテキスト ファイルで試したときの画面です。
当時は英語の表示でした。

入れる前は、指示に書いた「わからないことは、わからないと答える」のとおりの答えでした。
入れたあとは資料の内容で答え、どのファイルを見たかが回答の下に出ています。

出典が付くので、答えをそのまま信じずに元の資料を確かめられます。
社内で使う場合は、ここが大事だと考えています。

先に知っておく制限

画面に出ていた条件のほかに、Microsoft Learn のナレッジのページに制限が載っています。
初版を書いた7月の時点で読んだ内容は次のとおりです。
数字は変わることがあるので、使う前に Learn で確かめる前提です。

制限内容（2026年7月に Learn で確認）
ファイルの数1つのエージェントに最大500ファイル
SharePoint の権限質問した人が見られる資料からだけ回答する
環境の設定ファイルをアップロードして使うには、環境で Dataverse 検索が有効になっている必要がある

SharePoint をナレッジにすると、同じ質問でも、質問した人の権限によって答えが変わります。
この記事ではファイルのアップロードだけを試していて、SharePoint の動きは確かめていません。

この記事で確かめていないこと

  • いまの画面での、追加後の回答。クレジットが 0 だったため、回答の画面は7月のものです
  • 公開 Web サイト・SharePoint・OneDrive・Dataverse を追加元にした場合
  • 「詳細設定」のタブに並ぶ接続先。撮影時は読み込み中のままで、中身を確認できませんでした
  • Word や PDF を入れた場合の処理時間。試したのは小さなテキスト ファイル1つです
