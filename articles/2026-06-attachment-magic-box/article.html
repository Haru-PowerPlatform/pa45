メールに届いた添付ファイルを、自動で OneDrive に保存するフローを作ります。
議事録や見積書などを毎回手でダウンロードして保存する手間がなくなり、保存し忘れも防げます。

重い添付を PC にため込まず、決まった場所にまとめておけるのがメリットです。
タイトルの「魔法の箱」は、放り込むだけで中身がクラウドに整理される OneDrive のことだと思ってください。

やることはシンプルですが、毎日のメール処理にそのまま効きます。Power Automate を初めて触る人でも、画面のどこを押すかまで分かるように、手順をひとつずつ書いていきます。

 

完成イメージ ── 添付が「箱」に吸い込まれる

まず、できあがりの形を見ておきましょう。
届いた添付メールが、自動で OneDrive（魔法の箱）に保存されます。
設定したあとの作業は自動なので、手で保存する必要はありません。

ひとつだけ正直に。これをやっても受信トレイ自体の容量は減りません。
あくまで「PCにダウンロードしてため込まない」「リンクで共有する」「保存し忘れをなくす」ための仕組みです😊
 

用意するもの（プレミアム不要）

特別な準備はいりません。
会社や学校で配られる Microsoft 365 があれば、追加料金なし（標準コネクタだけ）で作れます。

  • Office 365 Outlook（いつものメール）
  • OneDrive for Business（保存先のクラウド）
  • Power Automate のサイト（make.powerautomate.com）

💡 ここがポイント

今回使う3つのアクションは すべて標準コネクタ。
プレミアム（有料）ライセンスは不要です。
 

はじめに：Power Automate へのサインイン

「そもそもどこから入るの？」という方へ。
Power Automate は、ふだん使っている 会社（や学校）の Microsoft アカウントでそのまま入れます。

🔑サインインの手順
  1. ブラウザ（Edge や Chrome）で make.powerautomate.com を開く
  2. 会社・学校のメールアドレス（Microsoft 365 のアカウント）を入力して「次へ」
  3. パスワードを入力してサインイン（多要素認証が出たら、いつものスマホ承認でOK）
  4. 画面が出れば準備完了。
    これが Power Automate の作業場所です

💡 入れないときは

個人用の outlook.com や gmail.com では一部機能が使えません。会社・学校で配られたアカウントで入るのが確実です。
会社でPower Automateが無効になっている場合は、情報システム部門に相談してみてください。

動かしてみる（テスト）

作ったら、本当に動くか確かめます。

✓テストして確認する
  1. 自分のメールアドレス宛に、適当なファイルを添付したメールを1通送る（件名フィルターを付けた人は件名に [保存] を入れる）
  2. 1〜2分待つ（自動で動きます）
  3. 指定した OneDrive のフォルダを開く → 添付ファイルが増えていれば成功！
  4. うまくいかないときは、Power Automate の 「実行履歴」を開くと、どこで止まったか色（緑＝成功・赤＝失敗）で分かります
 

つまずきポイント（先に知っておくと安心）

  • 保存したファイルが0KB・空っぽになる → ①の「添付ファイルを含める＝はい」を忘れているのが原因。
    ほぼこれです。
  • 同じ名前のファイルが上書きされる → 「ファイルの作成」は同名だと上書きします。
    残したいなら、次の応用でファイル名に日時を足します。
  • 署名のロゴ画像まで保存される → メール署名の画像も「添付」として届くことがあります。
    気になる場合はファイルサイズや拡張子で条件を足して絞ります。

応用：ファイル名に日時を足してかぶらないようにする

「ファイル名」を、動的コンテンツのかわりに 式（Expression）にして、こう書きます。

concat(formatDateTime(utcNow(),'yyyyMMdd_HHmmss'), '_', items('Apply_to_each')?['Name'])

こうすると 20260626_140530_見積書.pdf のように、かぶらない名前で保存されます。items('Apply_to_each')?['Name'] は「いまループで処理している添付の名前」という意味です。

 

まとめ

やったことは 3つのアクションを並べただけです。

  • ① メール受信トリガーで「添付ファイルを含める＝はい」にする（ここが肝）
  • ② Apply to each で添付を1個ずつ回す
  • ③ その中で OneDrive「ファイルの作成」に保存する

難しい式は使っていません。
それでも「添付を手で保存する」という毎日の小さな手間がなくなって、ファイルの置き場所が1つに揃います。“探す時間”を減らす自動化として、最初の1本にちょうどいいテーマだと思います。
