## #2 翌日（つまずき補足スレッド）

```
昨日の「添付を自動保存」フロー、
一番ハマるのがここです。

トリガーの詳細設定で
「添付ファイルを含める＝はい」

これを忘れると、フローは動くのに
保存されるファイルが空っぽになります。

逆にここさえ押さえれば、あとは並べるだけ。

#PowerAutomate #PA45 #PowerPlatform
```

## #3 1週間後（応用の一言）

```
「添付を自動でOneDriveへ」フロー、
同じ名前のファイルは上書きされます。

残したいときはファイル名を式にして
日時を足すとかぶりません。

concat(formatDateTime(utcNow(),'yyyyMMdd_HHmmss'),'_',名前)

作り方はブログに👇

#PowerAutomate #PA45 #PowerPlatform
```
